# 🔎 FindBack — Smart Lost & Found

FindBack is a web-based Lost & Found system designed for college campuses.

It allows students to report lost or found items, browse reports, search for items, and identify possible matches.

## 🚀 Features

- 🟢 Report found items
- 🔴 Report lost items
- 🔎 Search items by keyword
- 📍 Store item location
- 🗂️ Category-based filtering
- 🔄 Lost / Found filtering
- 🤝 Possible match detection
- 📱 Responsive web interface
- 💾 Browser-based data storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📌 How It Works

1. A student reports a lost or found item.
2. The item details are stored in the browser.
3. Users can browse and search available reports.
4. The system compares item information and displays possible matches.
5. Users can filter reports by Lost or Found status.

## 🎯 Problem Statement

Students often struggle to recover lost belongings on college campuses because there is no centralized platform for reporting and searching lost and found items.

FindBack provides a simple digital platform to make this process faster and more organized.
