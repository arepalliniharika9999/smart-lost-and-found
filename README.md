# 🔎 FindBack — Smart Lost & Found

A responsive **Lost & Found web application** for college campuses. Users can browse lost/found reports, search and filter items, create new reports, and see possible matches.

## ✨ Features

- Lost / Found item reports
- Search by item, location and description
- Category filtering
- Smart matching based on category, location and keywords
- Dashboard statistics
- Responsive design for mobile and desktop
- Browser local storage for demo persistence
- No backend required

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## ▶️ Run Locally

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For the best development experience, use the **Live Server** extension in VS Code.
